# Il mio primo progetto

Un «Ciao mondo!» per sorridere: un'albicocca che saluta il mondo, ogni volta in una lingua diversa.

**Provalo su [codice.albicocchepelate.it/il-mio-primo-progetto](https://codice.albicocchepelate.it/il-mio-primo-progetto)** e tocca l'albicocca.

## Com'è fatto

Tre file nella cartella `demo/`:

- `index.html`: l'albicocca e il fumetto;
- `ciao.css`: il saltello;
- `ciao.js`: l'elenco dei saluti e cosa succede a ogni tocco.

Font, colori e mascotte arrivano dal kit del sito (`/kit/`), così lo strumento sembra di casa.

Ogni grande viaggio comincia con un «Ciao mondo!».
